# Perfetto UI 的最小使用配方

打开 <https://ui.perfetto.dev/> 并加载真实 `.pftrace`；不要为了漂亮截图而重复 GUI 自动化。

| 分析路线 | UI 轨道/操作 | SQL 对照 |
|---|---|---|
| CPU 调度 | CPU 0..N Scheduler；展开目标进程线程轨道，看 Running/状态变化和整核 busy | `01`、`02`、`08` |
| Runnable 等待 | 选 Thread state 的 `R`/`R+`，与唤醒和 CPU slice 对齐 | `03` |
| CPU 频率/Idle | CPU Frequency/Idle tracks，同窗观察调度与波动 | `04` |
| 周期尖峰 | SQL Query → Add Debug Track → Counter：ts、cpu_ms、Pivot utid | `05` |
| Spike episodes | SQL Query → Add Debug Track → Slice：ts、dur、name（可在 SQL 中追加常量），单位 ns | `06` |
| 采样热点 | 选目标进程 Perf Samples → Flamegraph，确认样本/符号 | `07`、`linux.perf.samples` 标准库 |

图表展示必须标真实 UPID/UTID、时间窗口、单位和数据质量；CPU 调度时间桶是统计结果，不能作为事件级真实调度轨道的替代。若没有 GUI 能力，输出 SQL 与本地打开步骤，状态为 `UI_UNKNOWN`，不虚构截图。
