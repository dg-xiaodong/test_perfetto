# HDR（ISP HDR 寄存器记录）

RDK X5 / ISP8000 V62x（`isp8000_6_2_0_rc0s`）在 HDR 场景下的 ISP 寄存器落盘与官方寄存器手册。

## 文件

| 文件 | 说明 |
|---|---|
| `isp_sc230ai_regs.txt` | SC230AI 传感器配置下的 ISP 寄存器 dump |
| `isp_ov50q40_regs.txt` | OV50Q40 传感器配置下的 ISP 寄存器 dump |
| `Vivante.ISP8000.Series.V62x.Accessible.Registers-00A3-v0.80_isp8000_6_2_0_rc0s-B-20230718.pdf` | 官方寄存器手册（00A3 / v0.80，536 页 A4，2023-07-18 生成），用于查地址含义与位域 |

## 寄存器 dump 格式

- 每行一条：`<地址> <数值>`，均为十六进制，例如 `0x3d000410 0x00000780`；
- 每个文件 576 行，地址范围 `0x3d000000` – `0x3d005ffc`（4 字节步进，ISP 寄存器空间）；
- 两份 dump 直接可用 `diff` 对比：共 188 行不同（其余 388 行一致），传感器相关配置集中在 `0x3d0004xx` / `0x3d0005xx` 等区段。

## 用法建议

1. 先按地址在 PDF 里查寄存器名/位域，再对照两份 dump 的差异判断哪些属于“传感器相关配置”，哪些属于 HDR 处理链路；
2. 差异示例：`0x3d000410` SC230AI `0x780` vs OV50Q40 `0xF00`，`0x3d000414` `0x438` vs `0x870`（具体语义以手册为准）；
3. 若要复现/回灌：按 `addr value` 顺序写寄存器即可，注意写前确认时钟/复位与当前 pipeline 状态。
