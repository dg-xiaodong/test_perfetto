# Agent 行为对照（旧版 v1.0.0 vs 候选 v1.0.1）

## 条件（如实记录）

- 两个**独立会话**（subagent，同一宿主模型与工具集），互不可见，也不共享本维护会话上下文；
- 旧版组加载已安装的 `/root/.dsh/skills/perfetto-memory-debugging`（v1.0.0）；候选组加载 `/root/code_1.0.20/tmp/skill_candidate/candidate-v1.0.1`；
- 两组收到**完全相同**的 T1/T2/T3（`tests/agent_ab/T1..T3`），不含历史纠错与预期答案；均被要求不读候选目录外的诊断/报告/历史；
- 原始首轮输出：`candidate-v1.0.1/tests/agent_ab/R1_old_skill_raw.md`、`R2_candidate_skill_raw.md`（未改写）。
- 局限：候选组是"按路径加载候选版"，不是部署环境；两组均为单次首轮、样本量 1；评分为维护者按 `rubric.md` 事后判定。

## 评分（每任务 0-3）

| 任务 | 判据 | 旧版 | 候选 |
|---|---|---|---|
| **T1** 执行前提 | ①按"实际启动名 basename"比对；②指出不匹配会匹配失败 **且 BLOCKING_INIT 可能挂起**；③区分静态检查与运行期证据 | **2/3**（①②中只做到②的前半：说了"静默失败"，未提挂起） | **3/3** |
| **T2** 目标发现 | ①候选覆盖路径名并输出 dump/记录数；②歧义规则 + 用户已给 UPID 不替换；③`-1`=未解析、0 行≠没有分配 | **3/3**（用 `GLOB '*memprobe*'` 能覆盖路径名，但会过匹配 `memprobe_arm64`） | **3/3** |
| **T3** A/B 判读 | ①interval ≠ 可见 dump 数（推进/去重）；②总量/free/live/符号判 PASS，精确区间判 UNKNOWN；③不因 dur=0 全判未知 | **2/3**（缺①：把 A 的 1 份 dump 判成"连续 dump 未生效/会话早停"的 FAIL；②把精确区间判成 FAIL 而非 UNKNOWN） | **3/3** |
| **合计** | | **7/9** | **9/9** |

## 关键差异（引用原文）

| 问题 | 旧版 | 候选 |
|---|---|---|
| 名称不一致的后果 | "精确匹配不命中…这是静默失败"（未提 `BLOCKING_INIT` 挂起） | "heapprofd 按 argv[0] basename 匹配 → 不匹配，永不被 profile；叠加 BLOCKING_INIT=1 时首次 malloc 等待初始化，**可能永久阻塞**" |
| A 组为何只有 1 份 dump | "只有启动 dump，连续 dump 未生效或会话早停/匹配过晚" → **A FAIL** | "free 以 ts=0 提交，窗口只随非零 ts 分配推进；TP 按 (upid,window_end,heap) 去重 → A 全分配全释放→窗口不前进→1 份" → **可解释，不判失败** |
| 精确持有 8s | **FAIL**（"8s 是上界候选而非实测值"） | **UNKNOWN**（"dur=0 → 窗口不可知；只能给上界证据"） |
| 目标候选 | 自定义 `GLOB '*memprobe*'`（会过匹配 `memprobe_arm64`） | 技能内 `[CANDIDATES]`（`name='X' OR name GLOB '*/X'`），`ambiguous` 显式输出 |

## 结论（不夸大）

- 候选版在 T1/T3 上把两个旧版失败点（`BLOCKING_INIT` 后果、`window_end` 去重与三态）变成可复述的规则，**有首轮原文为证**。
- 旧版 T2 同样满分——**目标发现这块旧版并不差**，候选版只是把它固化成可跑的查询与参数规则；不宣称"旧版不会做目标发现"。
- 样本量 1、候选组为路径加载，属于弱证据；不据此宣称普遍改善，仅记录本次对照结果。
